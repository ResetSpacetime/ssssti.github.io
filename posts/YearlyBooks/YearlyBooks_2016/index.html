2016 阅读

2017-01-05 | 阅读 | 1.9k 字 | 6 分钟

Jan

《愛默生家的惡客》
木心 / 2012 / INK 印刻出版公司
1.8 看木心的散文，有种上学时做题，不停翻看书后答案的感觉。 PS.大陆版删了《试问美国人》、《S·巴哈的咳嗽曲》、《咖啡弥撒》和《许愿》

《复杂》
梅拉妮·米歇尔 / 2011 / 湖南科学技术出版社
1.17 第一推动相见恨晚

《画的秘密》
[法国] 马克-安托万·马修 / 2016 / 北京联合出版公司 / 后浪
1.24 知己难觅。记忆宫殿。一个终点，两个答案，一个是入口，一个是出口。

Feb

None.

Mar

《批判性思维工具》
[美国] 理查德·保罗、琳达·埃尔德 / 2013 / 机械工业出版社
3.1 翻译用词很中性，读来可能就显得略乏味。喜欢11章“应对自身的非理性”、12章“如何甄辨新闻中的媒体偏见和宣教”。想像思维的真正自由，移民弱势的必然，易谬性，人类相信自己可以欺骗自己。思考“思考”再思考。

《思考，快与慢》
[美国] 丹尼尔·卡尼曼 / 2012 / 中信出版社
3.10 窄框架比较受启发。写得太罗嗦了。

《引爆社群》
唐兴通 / 2015 / 机械工业出版社 / 华章科技
3.11

Apr

《斐多》
柏拉图 / 2011 / 生活·读书·新知三联书店
4.23 要不就（还是先不排斥杨绛了吧……

《疑问集》
[智利] 巴勃罗·聂鲁达 / 2015 / 南海出版公司
4.24 哀伤在你面前 / 扛着你命运的旗帜

《精进》
采铜 / 2016 / 江苏凤凰文艺出版社
4.27 这一本偏整合，是个不错的窗口。喜欢1.4.5章，7章感同身受

May

《你看起来好像很好吃》
[日本] 宫西达也 / 2009 / 二十一世纪出版社
5.12

《大象的算术》
[德国] 赫姆·海恩 / 2010 / 连环画
5.12 失语

Jun

《莎士比亚、牛顿和贝多芬》
S.钱德拉塞卡 / 1995 / 湖南科学技术出版社
6.9 作者自己，是第二种科学家。

《中国古代文化常识》
王力 主编 马汉麟等执笔 姜亮夫、叶圣陶等审校 刘乐园修订 / 2014 / 北京联合出版公司 / 后浪
6.9 时间源头

《房间》
[爱尔兰] 爱玛·多诺霍 / 2012 / 人民文学出版社
6.16 相较于电影，说得得过于明白了

《当你在世界上迷路的时候》
[德国] 于尔克·舒比格著 [德国] 尤塔·鲍尔绘 / 2015 / 浙江文艺出版社
6.18 插图赞。喜欢前一半。

《安德的游戏》
[美国] 奥森·斯科特·卡德 / 2013 / 广西科学技术出版社
6.19 Not the same but equal.

《黑羊》
[危地马拉] 奥古斯托·蒙特罗索著 [阿根廷]米盖尔·卡里尼绘 / 2015 / 上海人民出版社 / 世纪文景
6.23 驴和笛子

Jul

《巴托比症候群》
[西班牙] 恩里克·比拉-马塔斯 / 2015 / 上海人民出版社
7.14 看至最后一页，Mazzy Star 在电台里吟唱着：waves crashing me by

《抵岸》
陈志勇 / 2011 / 连环画出版社
7.21 故事，无声、无言、无形、无尽头。

《阅读的时光》
马塞尔·普鲁斯特 / 2010 / 中国出版集团 / 中国对外翻译出版公司

《寫作風格的意識》
史迪芬·平克 / 2016 / 商周出版
7.26 科学家视角

《新千年文学备忘录》
[意大利] 伊塔洛·卡尔维诺 / 2015 / 译林出版社
7.27 视觉意象，用精确描写无限，轻与四两拨千斤，复杂与累积。

《都柏林人》
[爱尔兰] 詹姆斯·乔伊斯 / 2010 / 上海译文出版社
7.31 灰色的天空
