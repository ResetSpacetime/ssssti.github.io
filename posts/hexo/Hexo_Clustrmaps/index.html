Hexo 使用 Clustrmaps 以地图图示显示访客

2020-03-11 | Hexo | 阅读 | 484 字 | 1 分钟

缘起

在网上乱逛时遇到，觉得不赖，拿来调试下用了。以前的博客平台里，常常自带这种插件。觉得很怀旧！

样式不太满意，于是不想把它显示出来，用比较鸡贼的方式隐藏了，然后再去官网看数据。如果想把它显示出来的话，本方法就不太适用了，你可能需要再自己折腾折腾。

操作步骤

注册

在 Clustrmaps.com注册，我没有太仔细地看注册条款，此网站有可能会调取、使用你的访问数据，如介意请勿用。

自定义代码

  1. 右上角点击Create Your Widget，提交博客域名，选择样式，即创建成功；
  2. 右上角点击头像，下拉菜单选My Websites，点击Customize；
  3. Size 项点选Custom Size；
  4. Widget Colors 项将所有颜色改为纯白，即#ffffff；
  5. 在 Widget Code 项选Javascript based，复制 JS 代码。

修改 layout 文件

  1. 在 HTML2Jade 转换格式；
  2. 在博客目录下目录\themes\maupassant\layout\_partial找到footer.jade，最后一行粘贴 jade 代码，本行代码前应有两个空格缩进；
  3. 在这段代码中找到w=300，将其改为w=1，在网站上是不允许修改的，鸡贼就鸡贼在这里啦（这样就看不见了嘛……）

部署

hexo g -d 你懂的

其他

  1. 可以收藏一个链接（每个站点都有一个固定地址可以查看访问数据），放在友情链接里，方便想起时查看；
  2. 同样道理代码也可以放在其他 jade 文件里，我觉得放在页脚比较神不知鬼不觉，不过最好不要放在 head.jade 里，因为会影响页面加载速度；
  3. 在页脚用鼠标试试，你可以找到那个可以点击的像素点的！
  4. 如果您有不鸡贼的方法，在此特求指教一二！
